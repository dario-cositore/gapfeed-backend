# The GapFeed Project

> **We scrape the internet for pain so builders don't fly blind.**

---

**Website**: [gapfeed.com](https://gapfeed.com)
**Sources**: 12 platforms — Reddit, YouTube, HN, GitHub, DDG, RSS, Stack Overflow, Dev.to, Google News, GitHub Issues/Discussions, Product Hunt
**Signals collected**: 189,000+ and climbing
**Active gaps identified**: 30+
**Architecture**: 5 autonomous agents with AI-driven clustering and verification

---

GapFeed is a market intelligence engine that extracts real user pain from across the web — forum complaints, YouTube rants, GitHub issues, negative reviews — and organizes them into actionable "gaps": specific product problems at scale that represent building opportunities.

We don't ask people what they want. We watch what they **complain** about.
